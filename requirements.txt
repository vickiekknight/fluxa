# google-genai's own dependencies must be listed explicitly here: the
# Dockerfile installs this file with --no-deps, so pip skips transitive deps
# (packages named in this file are still installed). Without these the
# container's google-genai fails at import -- the first symptom was:
#   TypeError: _TypedDictMeta.__new__() got an unexpected keyword argument 'extra_items'
# from google-genai 2.x's PEP 728 TypedDicts, which need a newer
# typing_extensions than the Isaac Sim image ships (4.12.2).

# but the Isaac Sim image ships websockets 12.0 and both the streaming server
# and the port-8765 command server (start_isaacsim_stream.py / reach_task.py)
# depend on it. websockets is only needed for google-genai's Live API, which
# Fluxa doesn't use -- generate_content works fine on 12.0. Leave it alone.
